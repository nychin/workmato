# 番茄钟每日重置

在“设置 → 计时”中调整“番茄钟重置时间”，默认 00:00，使用系统本地时间。每天到达该时刻，长休周期进度和岩石上的当日番茄划线一起清零。历史统计不会删除，运行或暂停中的计时也不会被重置。

例如设置为 04:30，04:30 之前完成的番茄属于前一天，04:30 起重新计数。关闭应用跨过重置时间，下次启动时会自动进入新的一天；同一天重启会恢复计数和长休周期。

完整专注倒计时结束时增加一个番茄，包括鞭策专注；延时结束、完成任务庆祝和提前重置专注不会重复增加。显示叠加 `04_rock/count/1.png` 至 `10.png`，位于 `rock_base` 之上，最多显示十层。实际计数可以超过十个。

沿用原有“完成指定次数短休后进入长休”的周期规则。重置点前开始的休息不会带入新一天的长休周期，正在进行的长休仍按开始时的时长继续。

计数保存在 `userData/timer-daily.json`。首次启用时从既有历史统计补充当前番茄日的已完成数量；长休进度从零开始。设置、字段验证和提示覆盖中文、英文、日文。

验证：`node --test tests/*.test.cjs`；`scripts/timer-ui-smoke.cjs` 使用隔离数据加载真实番茄钟与设置页面，检查十层划线、显示上限、清零以及重置时间保存。

# 工作上下文助手

启动应用后，小番茄默认置顶显示。悬停展开三列便签，离开窗口 200ms 后收起；点击小番茄固定展开，再次点击恢复自动展开。按住小番茄可拖动整个窗口，拖动不会切换固定状态。主体尺寸为 433 × 225 DIP（原尺寸宽度增加约 10%、高度增加约 15%），系统缩放会影响物理像素尺寸。

- **Alt+N**：显示／隐藏临时便签。鼠标穿透开启时，隐藏后再次显示会恢复交互。
- **Alt+Z**：在前台工作窗口所属屏幕中央打开速记抽屉，并聚焦输入框。Windows 前台窗口查询失败时使用鼠标所在屏幕。
- **速记**：Enter 保存到保鲜区，Shift+Enter 换行，Esc 收起并保留未提交草稿。中文输入法选词时的 Enter 不提交。
- **速记窗口移动**：按住顶部拖动条移动窗口，输入区仍可正常选择文字。再次用 Alt+Z 唤出时重新居中。
- **Delete 删除条目**：点击左列条目后按 Delete，删除当前条目；归档列表同样支持。点击中列文本框进入全文编辑，文本框中的 Delete 仅删除文字。
- **保鲜区**：左列选择条目，中列编辑全文；加号新增。根据创建时间分为 0–30、30–60、60–90 分钟三档，绿色逐渐变为枯黄色。编辑不重置计时。
- **保鲜色条**：点击后变为番茄红、暂停过期并置顶；再次点击取消保鲜，从当前时间重新计时 90 分钟。
- **归档**：90 分钟后自动归档。左下角归档按钮切换查看，归档页可编辑、复制、删除或恢复条目。程序关闭期间的过期记录会在下次打开时归档。
- **普通文本框**：右列独立保存，底部复制／清空只作用于该列；中列的复制／删除只作用于当前条目。
- **透明度**：右上滑条调整至 20%–100%，重启后保留。
- **鼠标穿透**：右上鼠标按钮启用，按钮变为番茄红底白图标。便签保持展开，只有此按钮接收鼠标操作，再点一次恢复交互。系统托盘“恢复上下文鼠标交互”也可恢复。

数据保存在 Electron `userData/context.json`，开发环境沿用项目隔离的开发数据目录。记录与普通文本自动保存；条目级命令串行执行并原子替换文件，避免面板和抽屉互相覆盖。删除为永久删除。读取损坏文件时不会用空数据覆盖原文件。

## 实现与验证

沿用项目的 `shared` 类型契约 → `preload` 安全桥接 → 主进程窗口控制器／仓库分层。新页面加入 Vite 多页面构建，复用现有字体、透明窗口矩形命中轮询方式与用户数据目录。

```sh
npm run build
npx tsc --noEmit
node --test tests/*.test.cjs
./node_modules/.bin/electron scripts/context-smoke.cjs
```

Electron 冒烟测试使用项目内 `.context-smoke` 隔离目录，验证真实页面、焦点、保存、透明度和穿透恢复，并输出 `panel.png`。全局快捷键是否被其他软件占用取决于运行环境；失败时会显示提示。速记仅通过 Alt+Z 唤出，已移除托盘速记入口；托盘仍可打开上下文助手。
